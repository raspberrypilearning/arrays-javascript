**数组**是编程中的数据集合。

想象一系列链接在一起的变量，单个项被称为**元素**。

使用**索引**访问元素。

数组中的第一个元素位于索引 0。

```
 ___________ ___________ ___________  
| 元素 1 | | 元素 2 | | 元素 3 |
 ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
| 索引 0 | | 索引 1 | | 索引 2 |
```

你在**漫画人物**中将它用作英雄滑块。

方括号 `[]` 用于指代元素在列表中的位置。
